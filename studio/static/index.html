CHOOSE YOUR TRAINING MODEL
Prepare a training job
This form creates the instructions for one training run. Creating a configuration does not start training or use the GPU.
  1. Choose your prepared dataset. This uses the reviewed image and caption revision you just created.
  2. Name this run. Use a short label so you can recognize it in Run History. Each run gets its own saved files.
  3. Choose the number of steps. Start with a 20-step smoke test after changing a dataset. It checks that training works; it is not a finished character LoRA. After a successful test, 2,000 steps is a starting point for a full run.
  4. Create the configuration below. Then find the ready job in Run History, review its configuration, and click Start training. That separate action begins GPU work.

BEFORE YOU START
A little room for the GPU.
  1. Review every image and caption in the prepared revision.
  2. Unload models in ComfyUI or Ollama to free VRAM.
  3. Run a 20-step test after changing a dataset or installation.
  4. Start the full run, then compare intermediate checkpoints.
